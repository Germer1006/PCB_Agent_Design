# T1 过流和插电浪涌验证

在模块 A 下运行 `python .agents/skills/boost-system-design/scripts/run_all.py outputs/test_t1_protection_r2 --requirements inputs/course_requirements.json`。仿真结果、原始工况判定及每个工况的波形索引保存在该试验目录的 `sim.json`。

## 输出过流

| 工况 | 判据 |
|---|---|
| `S-ocp` | 逐步加载后，短时越过软件阈值但持续时间小于配置延时，且滤波后的峰值小于硬件阈值。PWM 不误锁存。 |
| `S-ocp__sw_trip` | 在硬件阈值以下保持软件过流。ADC 连续超限达到延时后关断并锁存，恢复原负载后仍无开关脉冲。 |
| `S-ocp__hw_trip` | 突加重负载，滤波后的输出电流越过硬件阈值。仿真在比较器采样步关断，恢复负载后仍保持锁存。 |

三类工况均检查电感电流峰值低于 Isat。它们验证输出过流引起的 PWM 封锁，关断后的二极管直通仍按电路计算。独立输入限流、比较器/DAC/TIM1 实际路径和实物时延在 SR34/SR46 保留。

## 插电浪涌

新增独立输入缓升方案的设计条件为 Boost 输入端最大斜率 1 V/ms，输入就绪前 PWM 关闭。仿真把连续电压斜坡施加在输入电容之前的保护电路输出端，分别检查电感峰值与电源峰值预算。电源电流预算将电感峰值、输入电容按最大斜率充电的电流以及辅助负载估计保守相加。该预算没有计入实际保护器件控制环振荡、电缆寄生及 LDO 自身上电峰值。

可选实现参考 TI TPS25947xx 的 dVdt 功能。按数据手册 8.3.5.1 节，3.3 nF 对应名义约 0.61 V/ms。它是电路实现参考，需按具体器件版本、容差、温度、输出电容和实测波形核定最大斜率。[TI TPS25947xx 数据手册](https://www.ti.com/lit/ds/symlink/tps25947.pdf)

实物关闭条件为：验证独立保护电路确实控制全部输入电容前的上升斜率，测量输入与电感电流峰值、PWM 禁止窗口及供电释放能量，确认与器件 SOA 和输入保护配合。仿真通过记录为 SR88，实物证据未提交时 SR53 仍为 WARN。

无缓升的直插对照单独保存在 `reference_cases`。当线性模型算到超过 Isat 时，波形用于指出磁饱和风险，不能作为真实峰值上界。
