# A 智能体评测：当前可运行部分

A 的交付物是设计智能体（技能指令、知识库、确定性工具、检查及交接协议）。r6 电源方案是其中一个验证案例。本工具目前只实现非同步 Boost，不能因为工具能算多组电压，就宣称支持任意电源拓扑。

## 已实现

`specs/` 包含 12 组与课程需求同 schema 的合成输入：11 组升压规格，1 组 Vin,max ≥ Vout。覆盖 Vin 4.5/5/5.5 V、Vo 9/12/15 V、Iout 0.3/0.5/0.8 A、纹波上限 3/5%。每份输入都明确标注合成来源，不改变课程需求或小组实物采购决定。

从仓库根目录运行（标准库，无额外依赖）：

```text
python A/eval/run_eval.py --output A/outputs/eval_preflight_new
```

输出目录必须不存在。每组保留需求、固定默认决策、calc/selection、stdout/stderr、退出码与结果；错误和超时也保留。`summary.json` 记录器件库及计算/选型源码的 SHA256（CRLF 统一为 LF，便于 Windows/Linux checkout 对照），`results.md` 汇总全部用例。

验证内容：

- 初算占空比和输入平均电流与基础解析关系一致，保护阈值次序合理。
- 入选器件通过对应硬性规则；无候选返回非零并保留原因。无效 override 的端到端停止行为另由 `scripts/test_agent_boundaries.py` 验证。
- 不可能升压的需求在 S5 被明确拒绝，不进入选型。

`tool_regression_summary.json` / `results.md` 是一次真实工具回归的快照。可用上述命令重现；它们不是模型回答或实物实验记录。`verified` 表示**工具行为符合此回归的断言**，不是完整方案合格率；`selected` 只表示 S6 初选完成。

## 已观察到的边界

固定默认策略下，5 组完成初算与选型，6 组缺匹配器件，1 组被正确拒绝。低电流规格也可能因固定纹波比要求更大电感，而当前库没有匹配候选；15 V/0.8 A 则同时受耐压、电流和保护器件覆盖限制。缺件不能证明规格物理不可实现；智能体应回到 S5/S6，查证扩库或调整允许修改的设计决策，不能偷偷放宽用户需求。

`end_to_end_summary.json` 另记录 r6 与 easy03 的完整工具复跑。两组均被门禁拦截并保留 80/80 步账本；easy03 的 6 个过流失败暴露固定负载比例/固定预期在新规格下的适用性问题，不能直接归因于控制器误触发。详见 [完整验证与失败定位](../docs/A-agent-validation.md)。这些仍是确定性工具记录，不是完整智能体模型评测。
