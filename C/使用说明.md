# KiCad 自动 PCB 设计助手

## 第一次生成

1. 解压后双击 `启动自动设计.cmd`。程序需要 Python 3.10 或更新版本（含 Tk），以及带有 Python 接口的 KiCad 10。本机已找到 `D:\KiCad\bin\kicad-cli.exe`。
2. 点「载入 Boost 练习原理图」，再点「自动布局布线」。程序从随附的 `Boost练习.kicad_sch` 导出网表，找到器件的封装，使用演示策略生成板框、器件位置和走线，再执行 KiCad DRC。
3. 在窗口点「打开 PCB」或「打开结果目录」。生成的 `.kicad_pcb` 可在 KiCad 编辑。逐项查看 `设计报告.md` 和原始 `DRC.json`，需要定位时在 KiCad 重跑 DRC 并点击相应条目。

`生成示例` 中也有本机的一次完整运行。输入为同包 MT3608 原理图，自动生成了 38 × 30 mm 的双层板、80 段线、3 个过孔。KiCad 10.0.8 检查结果为 0 个错误、0 条警告、0 个未连接、0 项原理图差异。

## 换成小组的原理图

选择已给元件分配封装的单页 `.kicad_sch`。使用工程自己的封装时，保留 `fp-lib-table` 和可以访问的 `.pretty` 库。使用多页原理图时可以在 KiCad 导出完整网表，再将 `.net` 或 KiCad XML 网表作为输入。旧 `.sch` 如果导出为空，请用原项目的网表。

当前布局器面向小型双层样板，支持顶面安装、规则外形封装和矩形板框。布局主要考虑封装间距、连接长度和可识别的 Boost 功率与反馈网络。默认信号线宽 0.25 mm、功率线宽 0.45 mm、铜间距目标 0.20 mm。项目要求不同，可以用命令行参数设置。跑完后会保留报告。布线未完或 KiCad 报错时，报告标明待处理项。

## 模型如何参与

选择「请 Codex 提出布局优先级」后，程序向已登录的 Codex 提交器件、焊盘与网络摘要，读取模型给出的网络优先级和同网焊盘配对，校验后交给布局器和布线器。布局器生成具体坐标，布线器生成铜线和过孔。若模型调用失败，程序用本地 Boost 规则继续，报告会记录策略来源。

`demo/布局策略.json` 是本次对话按随附原理图编写的计算策略，可以用 `--strategy` 重现相同的模型决策输入。

本机验证使用了随附的策略文件。当前测试环境中 Codex 子进程返回退出码 1，在线策略请求等待实机验证。本地布局布线和 KiCad 检查可独立运行。

## 查看输出

| 文件 | 内容 |
| --- | --- |
| `.kicad_pcb` | 自动生成的器件、板框、铜线和过孔 |
| `DRC.json` | KiCad 的原始设计规则检查结果 |
| `设计报告.md` | 输入、结果、未布线项、错误与警告统计 |
| `布局与布线.json` | 器件坐标、每段铜线、所用策略、候选方案结果 |
| `PCB顶层.png` 或 `PCB铜层.svg` | KiCad 生成的板图 |

板级 DRC 是当前规则下的检查。正式课程板还要核对开关回路、采样、接地和接口，并用你们实际的器件、载流、温升和纹波要求判断初版。

也可在该助手目录打开 PowerShell 执行：

```powershell
python -B auto_pcb.py --demo
python -B auto_pcb.py --demo --strategy "demo/布局策略.json"
python -B auto_pcb.py "C:\path\your.kicad_sch" --size 50 35 --signal-width 0.25 --power-width 0.5
```
